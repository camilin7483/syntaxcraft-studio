# Changelog

- Prepared source and installable VSIX distributions for five extensions.
- Added ten original color themes, native semantic and TextMate token rules, and a catalog of language capabilities.

- Added the Control Center with contrast feedback, reversible settings, and portable JSON profiles.
- Added Organizer commands for provider-backed formatting, import organization, and reviewable whitespace edits.
