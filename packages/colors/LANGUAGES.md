# Language coverage

The registry pairs a VS Code language ID or embedded grammar context with the selectors Control Center can emit. Each row can provide TextMate scopes, semantic token types and modifiers, or both. **Auto** writes both mechanisms where they are available. Language rules use native semantic qualifiers such as `method:typescript` and TextMate parent scopes such as `source.python comment`. The editor applies its own selector specificity and puts semantic styling on top of lexical styling. [VS Code language identifiers](https://code.visualstudio.com/docs/languages/identifiers), [Semantic highlighting](https://code.visualstudio.com/api/language-extensions/semantic-highlight-guide), [TextMate highlighting](https://code.visualstudio.com/api/language-extensions/syntax-highlight-guide)

Separate controls need separate classifications from the active provider. The built-in JSON, Python, PHP, and Java grammars give their boolean and null-like literals one shared lexical scope. The argument category applies to emitted argument labels, such as keyword arguments in Python and argument labels in Swift. The object category applies to explicitly scoped receivers. JavaScript and TypeScript provide semantic methods and declarations. Their TextMate call pattern can match both standalone and member calls when semantic information is unavailable. [Bundled grammars](https://github.com/microsoft/vscode/tree/main/extensions), [SourceKit semantic token source](https://github.com/swiftlang/sourcekit-lsp/blob/main/Sources/SwiftLanguageService/SemanticTokens.swift)

TextMate matches dotted scope prefixes. A rule rooted at `source.js` can also match where the grammar uses `source.js.jsx`, and `source.css` is shared as a prefix of the SCSS and Less scopes. The more specific TextMate rule can be used in those modes. Semantic selectors use the exact language ID. Template grammars and fenced code can expose both outer and embedded scopes, so a single token can match several rules. [VS Code TextMate matcher](https://github.com/microsoft/vscode-textmate/blob/main/src/theme.ts)

The compiler is unit tested. Representative bundled grammar scopes were checked against VS Code 1.100.3. Third-party entries are mappings against upstream grammar and provider sources. Their installed versions, project context, and settings determine the tokens the editor receives.

## Verificación en el editor

Coloca el cursor sobre el símbolo y ejecuta **Developer: Inspect Editor Tokens and Scopes**. El panel muestra los scopes TextMate y, si está activo, el tipo de token semántico. Las plantillas pueden combinar su gramática con la de JavaScript, TypeScript, HTML, PHP u otros lenguajes. [Inspector de scopes de VS Code](https://code.visualstudio.com/api/language-extensions/syntax-highlight-guide#scope-inspector)
