# SyntaxCraft Studio Extension Pack

Instala SyntaxCraft Colors, Icons, Organizer y Control Center desde Visual Studio Marketplace cuando los cuatro paquetes estén publicados. Para una instalación local, instala los cuatro VSIX individuales antes del VSIX del pack. Abre **SyntaxCraft: Open Control Center** desde la paleta de comandos.

Installs SyntaxCraft Colors, Icons, Organizer and Control Center from Visual Studio Marketplace once the four packages are published. For local installation, install the individual VSIX files before the pack VSIX. Run **SyntaxCraft: Open Control Center** from the Command Palette.
