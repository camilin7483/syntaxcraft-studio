# SyntaxCraft Control Center

## Español

Ejecuta **SyntaxCraft: Open Control Center** desde la paleta de comandos de VS Code. Usa **Estudio de color** para preparar reglas por lenguaje, **Perfiles** para guardar e importar JSON y **Ajustes** para recuperar valores previos. **Aplicar ajustes** solicita confirmación y usa el ámbito Usuario o Proyecto seleccionado.

Instala SyntaxCraft Colors para activar sus temas, SyntaxCraft Icons para activar los conjuntos de iconos y SyntaxCraft Organizer para usar sus comandos. La vista previa del panel ofrece un ejemplo. El editor real usa los selectores de su gramática y proveedor.

## English

Run **SyntaxCraft: Open Control Center** in the VS Code Command Palette. The Color Studio edits per-language token rules, Profiles saves and imports portable JSON, and Settings restores earlier values. Apply changes after reviewing the active User or Workspace scope.

Install SyntaxCraft Colors, Icons, and Organizer to enable their themes, icon sets, and editor actions. The actual editor highlights with its grammar and language provider. The panel uses a local code sample for comparison.
